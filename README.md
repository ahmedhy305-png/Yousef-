# Yousef - تعلّم حل مكعب روبيك + مدرب Gemini الذكي

تطبيق ويب تفاعلي بالعربية لتعلّم حل مكعب روبيك ثلاثي الأبعاد عبر 7 خطوات للمبتدئين، مدمج معه **مدرب روبيك الذكي** باستخدام **Gemini Interactions API**.

## الميزة المضافة (Gemini API)

- **نموذج الذكاء الاصطناعي**: `gemini-4-hydrogen` عبر نقطة النهاية الرسمية `POST https://generativelanguage.googleapis.com/v1/interactions`.
- **تحليل حالة المكعب الفعلية**: يقرأ التطبيق ألوان الأوجه الستة الحالية للمكعب ثلاثي الأبعاد، الخطوة المفتوحة، وآخر الحركات المنفذة.
- **مخرجات مهيكلة (`response_format`)**: يُرجع المدرب شرحًا بالعربية، نصيحة للمبتدئ، رقم الخطوة المناسبة (1–7)، وتسلسل حركات قياسي يمكن تشغيله مباشرةً على المكعب بزر **"شغّل الحركات على المكعب"**.
- **محادثة متصلة (`previous_interaction_id`)**: يدعم الأسئلة المتتابعة مع زر لبدء محادثة جديدة.

## طريقة الاستخدام

1. افتح الملف [`index.html`](./index.html) في المتصفح (أو انشره عبر GitHub Pages).
2. افتح قسم **إعداد مفتاح Gemini API** في بطاقة المدرب وأدخل مفتاحك من [Google AI Studio](https://aistudio.google.com/apikey) (يُحفظ المفتاح في `sessionStorage` داخل متصفحك فقط للجلسة الحالية).
3. جرّب أزرار **حلّل وضعي الحالي**، **تلميح للخطوة الحالية**، **تمرين سريع**، أو اكتب سؤالك مباشرة.
